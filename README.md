# ระบบออกใบเบิกพัสดุและจัดการสต็อก (A5 Landscape Requisition System)

โปรแกรม Desktop Application สำหรับติดตั้งลง PC (Windows) พัฒนาด้วย **Python + CustomTkinter + SQLite** พร้อมระบบออกเอกสารใบเบิกขนาด **A5 แนวนอน** ภาษาไทยสวยงาม

---

## 🌟 จุดเด่นและฟังก์ชันการทำงาน

1. **ออกใบเบิกพัสดุ (A5 แนวนอน):**
   - รันเลขที่เอกสารอัตโนมัติ (เช่น `REQ-202609-0001`)
   - เลือกพัสดุ/สินค้าจากสต็อก พร้อมแสดงยอดคงเหลือแบบเรียลไทม์
   - **ระบบตัดสต็อกอัตโนมัติ** เมื่อกด "บันทึกและพิมพ์ PDF"
   - สร้างไฟล์ PDF ขนาด A5 แนวนอน จัดหน้าสวยงาม ตัวอักษรภาษาไทยคมชัด ไม่มีปัญหาสระลอย
   - เปิดไฟล์ PDF ให้ดูและสั่งพิมพ์ออกเครื่องปริ้นเตอร์ได้ทันที
2. **จัดการสต็อกสินค้า (Inventory):**
   - เพิ่ม / แก้ไข / ลบ รายการสินค้า
   - รับของเข้าสต็อก (Restock) ได้สะดวกรวดเร็ว
   - ระบบเตือนสต็อกใกล้หมด (เมื่อต่ำกว่าจุดเตือน)
   - ค้นหาสินค้าตามรหัสหรือชื่อ
3. **ประวัติและพิมพ์ซ้ำ (History):**
   - ค้นหาประวัติใบเบิกย้อนหลังตามเลขที่, ผู้เบิก หรือแผนก
   - สั่งพิมพ์ซ้ำ (Re-print PDF) ได้ทุกเมื่อ
   - ระบบยกเลิกใบเบิก พร้อม**คืนสต็อกอัตโนมัติ**
4. **ตั้งค่าระบบ (Settings):**
   - ปรับเปลี่ยนชื่อบริษัท / องค์กร ที่จะแสดงบนหัวเอกสาร
   - ปรับชื่อหัวเอกสาร
   - กำหนดชื่อบทบาทผู้ลงนาม 3 ช่อง (เช่น ผู้ขอเบิก / ผู้อนุมัติ / ผู้จ่ายพัสดุ)

## ⚡ การคีย์แบตเตอรี่แบบเร็ว

- กด `F2` เพื่อไปยังช่องคีย์ด่วนจากทุกจุดในหน้าใบเบิก
- พิมพ์รุ่นหรือ `รุ่น*จำนวน` แล้วกด Enter เช่น `Q100*2`
- ระบบจะเปิด popup แสดงยี่ห้อ รหัสเต็ม ชื่อสินค้า ความจุ และสต็อก เพื่อให้ตรวจสอบก่อนเพิ่ม
- ใช้ช่องว่างแทน `*` ได้ เช่น `FB N100 4`
- การค้นหาไม่สนตัวพิมพ์เล็ก/ใหญ่ ช่องว่าง หรือขีด เช่น `55d-23l*4`
- ถ้ารหัสเดียวกันมีหลายยี่ห้อ ให้ใส่ยี่ห้อหน้ารุ่นเพื่อป้องกันเลือกผิด เช่น `FB N100*2`
- กด `Esc` เพื่อล้างคำค้นหาอย่างรวดเร็ว

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. ติดตั้งไลบรารีที่จำเป็น
```bash
pip install -r requirements.txt
```

### 2. รันโปรแกรม
```bash
python main.py
```

---

## 📦 วิธีแปลงเป็นไฟล์ติดตั้ง .exe สำหรับ Windows PC

ใช้ workflow `.github/workflows/build-windows.yml` เป็นวิธีหลัก ระบบจะ:

1. สร้างโปรแกรม Python 3.8 แบบ x86 และ x64 แยกกัน
2. รัน self-test กับทั้งสอง payload
3. รวมเป็น Universal Setup ไฟล์เดียวด้วย Inno Setup
4. ทดสอบติดตั้ง เปิดใช้งาน ถอนติดตั้ง และตรวจว่าข้อมูลผู้ใช้ไม่ถูกลบ

ไฟล์ผลลัพธ์คือ `dist_installer/BatteryRequisition_Setup_v1.0.0.exe`

ดูขั้นตอนและข้อจำกัดใน [HOW_TO_BUILD_WINDOWS.md](HOW_TO_BUILD_WINDOWS.md)
